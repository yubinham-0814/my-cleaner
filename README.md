# 출장비 정리기

## 쓰기 전에

1. 넣은 파일은 브라우저를 떠나지 않습니다. F12 → Network 탭을 연 채로 파일을 넣어 보면, 화면을 열 때 읽은 화면 파일과 처방 파일 말고는 새 요청이 생기지 않는 것을 볼 수 있습니다.
2. 이 정리기는 진짜 값을 되살리지 못합니다. 빈칸, 0을 더 친 것 같은 금액, 월·일을 가릴 수 없는 날짜, 박수가 0인데 숙박비가 있는 줄은 고치지 않고 `_표시` 칸에 «확인이 필요합니다»라고만 적습니다. 처방에 없는 실수는 찾지 못합니다.
3. 무엇을 어떻게 고칠지(처방)는 [rules/](rules/)의 파일을 고쳐서 바꿉니다. 코드에는 처방이 없습니다.

## 무엇을 하나

출장비정산 엑셀을 화면에 끌어다 놓고 «규칙대로 정리»를 누르면 두 파일을 내려받을 수 있습니다.

- **정리본**: 처방대로 고친 표. 오른쪽 끝 `_표시` 칸에 확인이 필요한 칸이 적힙니다.
- **바꾼 기록**: 고친 값 · 표시한 행 · 지운 행과 각각의 이유.

정답 파일이 있으면 «정답과 대조»에서 내 컴퓨터의 파일을 골라 맞대 볼 수 있습니다. 정답 파일은 사이트에 두지 않습니다.

## 처방 고치기

- 처방은 [rules/출장비정산.json](rules/출장비정산.json)에 있습니다. 처방마다 하는 일(`what`), 이유(`why`), 정한 사람(`owner`)이 적혀 있습니다.
- 표시하는 처방에는 정리기가 읽는 조건 `check`도 함께 적습니다. 뜻은 `what` · `when`과 같아야 합니다.
- 새 처방 파일을 만들면 [rules/index.json](rules/index.json)의 목록에 이름을 더합니다. 엑셀 파일 이름과 처방 파일 이름이 같아야 자동으로 찾습니다. 예: `출장비정산.xlsx` → `rules/출장비정산.json`

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | 화면 |
| `clean.js` | 처방을 읽어 그대로 실행하는 엔진 |
| `lib/` | 엑셀을 읽고 쓰는 [SheetJS](https://sheetjs.com) 0.20.3 (Apache License 2.0, `lib/LICENSE`). 다른 사이트에서 불러오지 않습니다 |
| `rules/` | 처방 |
| `data/출장비정산.xlsx` | 시험용으로 지어낸 엑셀 (개인정보 없음) |

## 내 컴퓨터에서 열기

`index.html`을 더블클릭해서 열면 브라우저가 처방 파일 자동 읽기를 막습니다. 이때는 처방 파일을 직접 고르면 됩니다. 폴더를 웹 서버로 띄우면 자동으로 읽습니다. 예: `python -m http.server 8000 --bind 127.0.0.1`
